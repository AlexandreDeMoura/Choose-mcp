# Choose MCP

MCP server leveraging [MCP Apps](https://modelcontextprotocol.io/docs/extensions/apps) to display live sales data from [Choose](https://www.appchoose.io/).

It fetches data from the public endpoint: `https://api.appchoose.io/app/sales/live`

## Install

```bash
npm install
```

## Commands

```bash
# Development (watch mode)
npm run dev

# Build
npm run build

# Start (after build)
npm start
```
